# RepoLens

### AI-Powered GitHub Repository Analyzer

RepoLens is a web-based developer tool that analyzes a public GitHub repository and converts its codebase into a clear, visual overview.

Instead of manually exploring folders, configuration files, dependencies, and source code, RepoLens provides a centralized dashboard showing the repository's architecture, technology stack, project structure, and overall project health.

---

## Features

### Repository Analysis

Enter a public GitHub repository URL and RepoLens analyzes the repository to generate:

- AI-powered project summary
- Repository architecture
- Technology stack
- Repository structure
- Configuration files
- Dependency information
- Project health observations

### RepoMap

RepoLens automatically generates a visual representation of the repository architecture.

The RepoMap shows how major parts of the project are organized and connected, making unfamiliar codebases easier to understand.

### Tech Stack Detection

RepoLens identifies technologies used within the repository, including:

- Programming languages
- Frameworks and libraries
- Configuration files
- Dependency files
- Repository structure

### Project Health

The dashboard provides a quick overview of repository characteristics and potential project observations.

### AI-Powered Insights

RepoLens uses AI to transform repository information into an easy-to-understand explanation of the project.
